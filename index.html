🔥 綜合熱傳係數 h 的計算原理

本工具採用動態 h(FH) + 動態 η_fin 鰭片效率耦合物理模型，經多款 5G RRU 實機 CFD 校準：
• h_conv = 6.4 × tanh(Gap / 7.0) × (70 / FH)0.20　→ 對流項加入鰭片高度修正（FH 越長邊界層越厚、h 越低）
• h_rad = 2.4 × min(1, √(Gap / 10))　→ 輻射項，Gap ≥ 10mm 飽和、Gap < 10mm 隨間距衰減
• η_fin = tanh(m·Lc) / (m·Lc)，m = √(2h / (k·t))，Lc = FH + t/2　→ 鰭片溫度梯度造成的效率折扣（典型 0.85 ~ 0.95）
• 有效效率 eff = η_fin × η_process（η_process：Embedded Fin = 1.06 / Die-casting = 0.99，含底板與製程修正）
由於 h 與 η_fin 皆隨鰭片高度 FH 變化、而 FH 又由兩者反推求得，工具採用迭代收斂演算法解出唯一自洽解。
與舊版固定 h 模型相比，新模型能正確反映高 T_amb 高功率情境下鰭片變長後 h 的衰減與效率損失，經 CFD 比對 FH 預測誤差顯著改善。

🔍 設計規則檢查 (DRC) 總覽

📏 通用規則 (Universal)

  • 流阻比 AR ≤ 12（超過即 Choked Flow）
  • h_conv ≥ 4.0（Gap 過小則對流不足）
  • Gap ≥ 4mm（物理極限）

🔧 Embedded Fin 規則

  • 鰭片高度 FH ≤ 100mm（製程限制）

🏭 Die-casting SSM 規則

  • T_tip（鰭片尖端厚度）≥ 1.0mm
  • 拔模角 α ≥ 0.5°
  • T_root 根部厚度 = T_tip + 2 × FH × tan(α)
  • G_root 根部間隙 = Pitch − T_root > 0（根部不可重疊）
  • G_root ≥ G_min = max(C1, C2, C3)
    • C1 = max(3.0, 0.08 × FH)　模具鋼強度
    • C2 = 4.0mm　自然對流邊界層
    • C3 = 2 × T_tip　模具充填
  • AR 高寬比 = FH / T_tip ≤ 45（SSM 極限），> 25 需 Cross Rib + 真空 SSM
  • FH ≤ 80mm（SSM 極限），> 30mm 建議配置 Cross Rib

⚠️ 使用注意事項

  • 本工具為快速概念設計與尺寸評估用途，非最終驗證級熱模擬
  • 計算結果高度依賴輸入參數準確度，請使用實際量測或 Datasheet 數值
  • 自然對流模型基於垂直鰭片、無風環境，室外高風速情境需另行評估
  • 建議將計算結果與 CFD 或實測進行交叉驗證
